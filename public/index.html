About the # column when sorting:

  • By default, # is the rank by Global Total Distance. When sorted by another column, # is the rank within that column for the selected mode (1 = highest, ties share a rank), and the original Global rank is shown small on its left.
  • Name / Last Updated / Avg Speed / Speed vs Median: # is the Total Distance rank of the selected mode.
  • Region: shown as "rank / players in that region", ranked by Total Distance within the region.
  • Avg Speed / Speed vs Median: these two headers are linked. Both sort by the absolute difference from the median Avg Speed (players with data in the selected mode), ascending (closest to the median first) by default. Hover over a Speed vs Median value to see the median.
  • Multi-sort: clicking a column adds it as the next sort key (the small number in the header shows the priority); clicking it again toggles ascending / descending. Region groups the table, so each region is ranked by the other selected column(s). Use "Reset Sort" to go back to Total Distance only.
  • Players with no data for the selected mode / column are shown as N/A and always listed below the lowest rank, regardless of sort direction. Ranks are calculated over all registered players, not just search results.
